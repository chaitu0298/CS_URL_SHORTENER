Import the matching collection + environment into Postman. For local Compose use the default `baseUrl` and `apiKey=local-demo-key` (Authorization header is ignored in API key mode). For AWS deployment, set `baseUrl=https://go.your-domain.com` and `accessToken` to a valid **Cognito access token** (the X-API-Key header is ignored in JWT mode). The collection creates, lists, measures, and revokes URLs. Disable "Follow redirects" if you want to inspect the 302 response. Revoke is destructive for the target code: recreate another code for further testing.
