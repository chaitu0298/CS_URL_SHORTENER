# AWS-ready URL Shortener — NodeJS backend

Use \'docker compose up --build\' in this directory for a local PostgreSQL database and API. See the top-level \'../README.md\' and \'../aws/DEPLOY.md\' for API behavior, production configuration, HTTPS+ECS+RDS deployment, Cognito and frontend integration. No frontend API key in production.

The original agentic SDLC workflow implementation is preserved. Its earlier example artifacts are historical evidence, not PostgreSQL production run evidence.
